An ultra-luxury architectural portfolio and interactive residential atelier built with React 19, TypeScript, Tailwind CSS, Three.js, and Motion.

## ✨ Key Features

- **Cinematic Scroll Timelapse**: Scroll-driven video and high-resolution photorealistic construction timeline showing the step-by-step genesis of cliffside estates.
- **Obsidian Dark Luxury Theme**: Curated obsidian (`#0C0C0B`), champagne gold (`#C5A059`), and titanium finishes.
- **Interactive 3D Architectural Massing**: Real-time Three.js viewport with travertine material toggles, blueprint wireframe mode, and solar angle simulation.
- **Curated Residences & Filter System**: Interactive property showcase with live bedroom/type filtering, specification modals, and downloadable architectural brochures.
- **Shortlist & Saved Drawer**: Persistent client shortlist system with slide-out curation drawer.
- **Interactive Connectivity & Radar Maps**: Clifftop estate travel times with animated radar beacons.
- **Architectural Journal & Monograph Modals**: Deep-dive essays on noble materials, spatial acoustics, and lighting philosophy.
- **Private Inquiries & Advisory Modal**: Confidential consultation booking form with validation.

## 🛠️ Tech Stack

- **Framework**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS, Vanilla CSS, Obsidian Dark Design System
- **3D Graphics**: Three.js
- **Animations**: Motion (Framer Motion)
- **Icons**: Lucide React
- **Typography**: Cinzel, Playfair Display, Plus Jakarta Sans, Cormorant Garamond

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm or bun

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/darshilthummar09/meridian-real-estate.git
   cd meridian-real-estate
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
